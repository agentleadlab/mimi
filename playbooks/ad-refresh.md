# Ad Refresh — new life for tired hooks

Use this when someone pastes a hook (or a full ad) that has been running for a while and asks to refresh, rework, "make new versions of", or "fight fatigue on" it, or uses /refresh. The goal: the audience sees something new, but the idea that made it work stays the same.

## Step 1: Diagnose the original (keep this short)
Name the 4 parts of the hook in one line each:
- **Who it qualifies:** the "If you…" condition (e.g. CDL holder with a current DOT card).
- **Core idea / promise:** what they get or learn (e.g. a private cash-building plan most drivers never hear about).
- **Proof or detail:** the specific thing that makes it believable (e.g. the DOT medical card).
- **Emotion:** the feeling it runs on (e.g. discovery, false security, fear of leaving family with debt).
The **core idea and the qualifier stay locked.** Everything else can change.

## Step 2: Write 5 refreshed versions (or the number asked)
Each version changes all three levers, and no two versions use the same combination:
1. **New opening:** a different first 3–5 words and setup pattern. Rotate through: condition → revelation, condition → question, condition → urgency, condition → social proof gap, condition → "most people think X, actually Y", condition → mini scenario ("Picture getting the call from dispatch…"). Never present an invented story as a real customer.
2. **New detail:** swap the concrete specific for another true one from the same world (a different trigger moment, number already approved, object, place or time). E.g. DOT card → renewal date, annual physical, 11-hour clock, truck payment, layover, lumper fee. Never invent statistics, results or guarantees.
3. **New emotional angle:** move to a neighboring emotion that fits the same idea. E.g. discovery → pride, discovery → frustration at being left out, discovery → protectiveness of family, discovery → urgency of a closing window.

## Rules
- Follow the vertical's playbook if there is one (for trucker hooks: every hook starts with "If you…" / "If your…", no emojis, never "life insurance" in the hook, the same banned words). Otherwise, match the original's tone and length (± about 20%).
- Write to one person. Write in short, spoken sentences. No AI-sounding phrases.
- Don't just reword: if someone could read a version and the original back to back and feel it's the same ad, rewrite it.
- Keep claims as safe as the original or safer. If the original has a risky claim, keep the idea but soften it and note that you did.

## Output (one card)
Title: "Refresh: <short name of the idea>".
- **What we're keeping:** one line with the locked core idea and qualifier.
- **V1 … V5:** each is the hook text, then a small line: _Opening: <pattern> · Detail: <new detail> · Emotion: <new emotion>_.
- **New ad headlines:** 3 options, 5 words max, different from every hook.
- **Test plan:** one or two lines, e.g. "Run V1–V4 against the original in one ad set; keep the original's creative so only the hook changes. Kill anything that doesn't beat the original's CTR or CPL after ~$50 each."
If they also gave the primary text or post-hook, add **Matching post-hook** for the top 2 versions, updated to match the new opening's emotion.
